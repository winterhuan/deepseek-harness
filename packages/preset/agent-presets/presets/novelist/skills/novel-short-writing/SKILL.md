# 短篇：先定情绪，再定故事

短篇以情绪为目标，所有内容为情绪服务。它不是缩小的长篇：不多线、不铺世界观、不堆人物。

## 1. 执行规则

1. **先定情绪，再定故事**：动笔前确定目标情绪（下表六选一），说不清情绪目标的场景不写。
2. **一个核心支点撑一篇**：反转型围绕一次主揭示蓄力；无反转型围绕报应兑现或甜度递进积累期待。
3. **每句必须有用**：不推动剧情、不铺垫反转、不推高情绪的句子 → 删。
4. **开头 3 句定生死，结尾定传播**：开头必须有钩子；结尾必须有余韵。
5. **默认第一人称**：代入感最强。除非题材明确需要多视角（如悬疑），一律用「我」。

## 2. 情绪目标表

| 情绪 | 适合场景 | 常配题材 |
|---|---|---|
| 意难平 | 虐恋、遗憾、错过 | 追悔型感情线 |
| 反转震撼 | 悬疑、身份错位 | 悬疑、反套路脑洞 |
| 爽感释放 | 打脸、逆袭 | 世情打脸、复仇 |
| 治愈温暖 | 成长、亲情、友情 | 甜文、救赎 |
| 细思极恐 | 悬疑、心理 | 民俗怪谈、心理惊悚 |
| 共鸣感动 | 现实、职场、婚姻 | 世情 |

## 3. 核心框架

动笔前写一小段框架（可作 `short.md` 顶部注释或直接与作者确认）：

- 一句话梗概：主角 + 困境 + 反转 + 情绪落点。
- 核心支点：反转类型（身份/视角/动机/时间线/信息/认知）或无反转（报应兑现/关系兑现）；铺垫点。
- 情绪设计：开头/中段/反转/结尾的强度（1–10）；反转峰值前 1 节升温、反转后 1 节维持不骤降。
- 人设速写：主角一句话 + 关键角色一句话 + 关系。

## 4. 五段结构

| 段 | 占比 | 要点 |
|---|---|---|
| 开头 | 前 300–500 字 | 3 句内抓人。**开头零环境**：前 3 句禁止无事件承载的环境描写，必须是事件/对话/动作/信息炸弹之一；冲突前置或反常行为开篇 |
| 铺垫 | 30–40% | 用物件/数字/习惯建立羁绊；埋至少 3 个反转线索分散在不同节；每 2–3 节一个钩子；情绪逐节递增，不连续 2 节无变化；贯穿道具第 1 次出现 |
| 升级 | 20–30% | 冲突比上段升级（强度/范围/代价至少一项）；埋误导信息让读者猜错方向；数字/金额递增做叙事工具；一动一静交替 |
| 反转 | 10–15% | 一节内完成揭示不拖延；揭示后前面线索可回溯（读者能找到「原来如此」）；反转节情绪强度 > 前面所有节；贯穿道具第 2 次出现（意义被颠覆） |
| 结尾 | 5–10% | 安静细节收尾（一个物件/动作/短话），不写大段抒情；贯穿道具第 3 次出现（回扣） |

结尾类型按情绪选：余韵式（意难平）、呼应式（治愈）、开放式（细思极恐）、再反转（震撼）、金句式（共鸣）。

## 5. 格式

- 正文单文件 `short.md`（作者指定名字时从其指定），落工作区根目录。
- 相邻段落之间只用单个换行，不空行；小节标记全文统一（如 `###1.`）。
- 对话引号风格全篇统一。
- 字数：作者给了范围按范围；只给单一目标按其 95%–105%；都未给默认 8000–20000 字。

## 6. 写作纪律

- 每个场景让读者和主角一起经历：发生、感知、反应揉在同一段连续正文，不按维度分三段。
- 情绪可以直写，但后面要接场景里特有的动作或物件；没有具体承接的情绪总结句删掉。
- 情绪宁烈不温：冲突前置、爽点具体、台词带刺；以克制为爽感的桥段（心死、余韵）按题材收敛。
- 分批写，每批对照核心框架检查情绪位置与未回收线索；不足先补子事件/对话，不注水。

## 7. 精修

- 每句有用测试：删掉不影响理解/情绪/铺垫的句子删掉。
- AI 腔按 novel-deslop 处理；短篇的预告句与带主角偏色的审判句不机械删。
- 交付前：字数在锁定范围内、节数与框架一致、开头 3 句含钩子、结尾有余韵。
