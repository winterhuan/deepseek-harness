# 短剧资产图片提示词

把视觉事实写成可复用、可修改、可直接复制的角色板、场景板、道具板或状态图提示词，统一保存到 `剧集/<EP>/图片提示词.md`。每项用 `IMG-...` 标题，正文放在 `### 可复制提示词` 的引用块；`IMG-...` 只是该提示词条目的稳定 ID，不声明图片已生成或可用。源：Drama Skills 0.6.1（MIT）。

## 入口
有当前视觉设定即可直接开始；剧本只在提示词需确认剧情状态时连读。
先确认用途：身份板、造型/状态变体、地点板、道具板、组合 production sheet 或比较风格帧。
可复制正文语言：项目未配置时默认 `en`，同一任务保持一致；不能从创作者说明语言推断提示词语言。

## 工作流
1. 锁写本张图固定身份/状态/空间或比较变量。
2. 只读所需资产事实、视觉方向、负面约束与已提供参考图。
3. 按主体+身份锚点 → 当前变体 → 构图/视角 → 光色材质 → 背景边界 → 禁止项 写正文。
4. 每张参考只控制身份、造型、地理、构图或风格中的明确部分。
5. 检查身份与变体、文字政策、视角和光线是否互通。

## 提示词要求
- 开头先写对象与用途，不用风格词淹没身份。
- 只写当前图能同时满足的要求；多视图/状态对照写清版面关系。
- 保留稳定识别锚点，变体只改允许变化的部分。
- 避免无验证作用的质量词堆砌。
- 可见文字、logo、水印、界面、字幕明确允许或禁止（尊重文字贴图政策）。
- 正文可直接复制，不含占位符、流程说明、文件路径或 QA 结论。

## 完成与投产
每个点名对象都有明确用途、可复制正文、参考边界和禁止项且互不矛盾即完成。实际生成必须转 `$short-drama-produce`，先展示精确任务并取得显式确认；本技能不调用外部服务。五份文档齐备后可转 `$short-drama` 做一次机械核对。
