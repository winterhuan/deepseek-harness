# 长篇原著分析

把长材料变成**能被引用、能被反驳、能被接着用**的分析层。目标不是复述剧情，而是找出每一段承担的戏剧功能，并说明它在竖屏短剧里值多少钱。分析永远是候选；哪条线保留、哪些人合并、从哪里开篇，是创作者的决定，由 `$short-drama-develop` 立成改编契约。来源：Drama Skills 0.6.1（MIT），DSH 桥接适配 —— 章节索引用 DSH 可见的 read_file + 逐行偏移建立，不整篇喂入上下文。

## 材料前提

只分析创作者合法持有、拥有使用权的作品。只读的转化性工作：提取结构与功能，不复制原文成段落，不把原句搬进下游产物。通俗题材里的暴力/复仇/背叛/情爱张力/黑暗伦理是常规虚构叙事元素，照常做结构化提取；个别片段无法处理时跳过并记录，不因此中止整本——中止会让后续拿到一份有洞却看不出洞在哪的分析。

## 先判断入口

1. **只有书名没原文**：请创作者提供文件路径或粘贴正文。没有字节就没有 span，无法被引用反驳。
2. **有原文未建项目**：建立只读 `输入/` 与输出 `项目开发/source-analysis/_work/`；把原文字节复制到 `输入/` 后记录原始位置。
3. **有原文项目已建**：直接进入管道。
4. **已有部分分析**：读 `项目开发/source-analysis/_progress.md` 从断点续跑。

## 管道

`输入/` 为不可变输入，本阶段只读。产出落 `项目开发/source-analysis/`。

| 阶段 | 做什么 | 产出 | 停靠 |
|---|---|---|---|
| S0 | 章节索引 | `_index.json`、`_progress.md` | 索引有问题就停 |
| S1 | 改编价值快评（抽样） | `triage.md` | **停靠问创作者** |
| S2 | 逐章功能提取 | `chapters/ch-<N>-extract.md` | 覆盖率不足就停 |
| S3 | 剧情单元与节奏聚合 | `story-units.md`、`rhythm-and-emotion.md` | 阈值不达标就复核 |
| S4 | 人物归并与设定 | `characters.md`、`world.md` | — |
| S5 | 改编价值与分集候选 | `adaptation-value.md`、`episode-candidates.jsonl` | 交接 develop |

### S0 章节索引
索引是**唯一切片真源**。用 DSH 的 read_file/grep 逐行定位每种“章/回/节”独立短行的行号区间，写 `_work/_index.next.json`；每个条目带 `sequence` / `line_start` / `line_end`。只认一种编号单位（出现最多的那个，其余记进 `ignored_heading_units`）；只把短的独立行当标题（以章号开头的正文段落记进 `long_heading_lines_skipped`）；剔除开头目录块。它不做编辑判断。`_index.json` 有 `problems` 就停下报告——章号跳号、同卷重号、正文极少的章、无法解析的章号。改了原文必须重建索引，不沿用旧 span。

### S1 改编价值快评
判断这本书值不值得全量拆解。抽样 12 章（确定性、首尾必取），用 `triage.md` 覆盖：题材与类型、可用改编密度（`screen_ready` 单元占比）、制作负担分布、人物/世界观可迁移性、改编价值快评与建议投入。**停靠问创作者**是否继续。

### S2 逐章功能提取
按 S0 索引逐章切片（超长章再按场景二次分组），每章写 `chapters/ch-<N>-extract.md`，只记功能标签与依据，不复制原文段——返回给引用用例的是一行页码引用，不是原句。覆盖率不足就停下补索引。

### S3 剧情单元与节奏聚合
把章节提取聚合为连续剧情单元：哪个单元是持续引擎、哪个是填充、哪个有升级/兑现张力；写 `story-units.md`，再从单元密度/追读节奏写 `rhythm-and-emotion.md`。

### S4 人物与世界观归并
合并同一身份多章散件；标出冲突源、关系压力、信息权限。输出 `characters.md` 与 `world.md`。不直接改剧本或资产。

### S5 改编价值与分集候选
合并上面结论，写 `adaptation-value.md` + 候选 `episode-candidates.jsonl`，交给 `$short-drama-develop` 立契约。明确刻出“可改范围”与“待确认项”，不得批准自己的产物。

## 边界
分析层永远是候选，不代替创作者决定改编方案；不复制原文成段落；不建究研磨产出之外的创作文档。改原文要重建 S0 索引。
