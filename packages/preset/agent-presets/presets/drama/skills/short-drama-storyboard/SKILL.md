# 短剧分镜

把单集剧本落实为可制作的分镜写入 `剧集/<EP>/分镜.md`。资产图片提示词与分镜是兄弟分支，不互相等待。只有关键场次真的存在多个成立导演方案时，才在上下文比较覆盖方案；普通场次直接设计。来源：Drama Skills 0.6.1（MIT）。

## 工作流

1. 确认每个场景动作、对白、声音、画面文字和转折由哪些镜头承载。
2. 确定观众何时知道什么、对齐谁、空间如何揭示、转折落在哪个可见动作。
3. 每镜写清唯一职责、来源、时长、景别/机位、起点、终点、声音和视觉依据。
4. 锁定人物朝向/位置/视线/持物/出入口/屏幕方向与必要状态。
5. 冻结关键帧只从镜头起点选择，删掉终点才出现的文字/动作/姿态/道具状态。
6. 整集请求完成整集，末端一次报告覆盖、节奏与真实未决选择。

## 镜头要求

- 每镜唯一职责、明确来源、可见起止状态与可拍时长。
- 切镜必须带来信息/权力/情绪/空间或节奏变化；同义重复镜删掉。
- 同一动作不跨镜重复发生；终点应能成为下一镜可信起点。
- 关键信息可读性优先于装饰性运镜；竖屏构优先保证主体与反应可见。
- 复杂群戏先锁空间锚点与屏幕边界，再决定景别变化。
- 冻结关键帧只写此刻能看见的内容：文字/人物朝向/视线/持物/反射/遮挡可生成。
- 检查发现遗漏直接修正文档，不生成覆盖表证明自己检查过。

## 视觉依据与图片

- `IMG-...` 是《图片提示词.md》里的提示词条目 ID，代表条目本身，不代表图片已生成/已提供。
- 已有《图片提示词.md》且本镜需要其中条目时写「图片提示词项：`ID` + 中文名称 + 它控制的边界」；ID 必须匹配该文档可见末级标题。
- 没有或没有合适条目时写「图片提示词项：无」，再指向《视觉设定》的人物/地点/道具项。这是正常直接入口，不为继续分镜编造 ID。
- 「输入参考图：经典 `REF-...` 用创作者已提供或经确认生产且当前可读的实际图片；每个 `.rkREF-...` 同时写槽位顺序、用 `/` 分隔的相对路径、中文名、「控制」与「不得控制」范围；没有则「无」。不得把提示词条目、计划生成图或对话里的描述写成已有图片。

## 修订
保留未受影响镜 ID；拆镜/并镜/职责时说明哪些下游视频提示词需刷新，但不自动重写用户未点名的文件。

## 完成
点名范围原文都有镜头落实、职责不重复、空间与状态连续、起止边界可制作、关键帧可冻结即完成。视频提示词、生产与审查只在用户点名时开始；五份文档齐备后可转 `$short-drama` 做一次机械核对。
