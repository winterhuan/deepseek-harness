# 短剧写作

把单集意图写成可表演、可拍摄、会改变故事状态的 `剧集/<EP>/剧本.md`。来源：Drama Skills 0.6.1（MIT），DSH 桥接适配 —— 时长估算用 DSH 可见的 read_file 逐场切分按可数台词/动作行估算，不依赖外部 Python 脚本。

## 格式约定

只维护一份剧本 Markdown，不另建 episode card/beats/block index/录音表。一级标题 `# EP001 集名`，场景标题 `## EP001-SC001 内 · 地点 · 时间/天气`。对白写 `角色（可选表演提示）：台词`；生产标签 `[VO]`、`[OS]`、`[SFX]`、`[画面文字]`、`[连续性]`、`[转场]`。不要把含冒号的动作叙述误写成对白。

## 入口

- 有分集规划：读取本集进入状态、目标、转折、回报和交接事实。
- 只有想法/大纲：在上下文形成最小单集契约和因果节拍再直接写。
- 已有剧本：保留作者语言，只做用户点名的定点修订。
- 非规范文本要进入制作：保留原文，只做必要的场景/动作/对白/标签规范化。

## 工作流

1. 锁定本集承诺的观看体验、谁现在要什么、阻力、当集兑现和退出状态。
2. 只识别本集实际存在的发动机：艰难选择就检查两边价值；判断转折依赖争议证据就检查证明边界；前景化精确死线就检查动作容量；题面限次数/轮次/呼吸/节拍就检查每单位是否在边界内完成所需状态。没有时不硬补；输入已以它为主发动机时，要让它真正改变行动、关系或结果，不只点台词。
3. 在上下文排“因为—行动—结果—下一股压力”，不落盘节拍表；让物件/对白/沉默/空间/声音按题材承担必要工作。
4. 逐场定下不可替代功能、可见变化与场尾状态；主要戏剧功能的配角有自己的策略，事务性角色保持简洁。
5. 动作、对白、画外音、声音事实、画面文字写入同一份剧本。
6. 用户要整集就写完整集，场景批次自动续跑。
7. 交稿前静默反查：只验证本集承诺、人物行动有因果、题材语气一致；专项检查本集真正使用的选择/证据/有限单位/精确死线。自检长出输入没要求的机关则撤掉机关。
8. 局部修订保留无关段落；明确问题直接修正，只把真实剧情分叉交给用户。

## 写作要求

- 先服从输入已有事实/必须禁止/题材观看契约/退出状态；审查项与手艺默认只帮助实现要求，不反过来补造题面没有的精确数字、记录、资源、程序、关系或机关。
- 每场改变信息/权力/关系/情绪/物理状态或风险；无变化的场删掉或合并。核心阻力转向要有可追溯的事实、筹码、权限、代价或人物行动，不能只靠对手停止反应。
- 对白必须在争取、回避、试探、逼迫或重新定义关系；用可见行为表现状态，不用解释替代行动，也不把已演清的机制再说一遍。
- 压缩过程只保留会改变策略、关系、风险或结果的节点；资源与外部反应必须取自输入或前文，且不能替人物完成最难的行动。
- 承担主要冲突的角色保持相称的目标/判断/策略；事务性角色不硬加秘密、反转或弧度。
- 已建立代价、不可逆后果、关键持物与知识的状态进入可追溯的退出状态；结尾可推进、留白、反讽、安静收束或余韵。
- `[连续性]` 只交接由前文动作已建立又易在下游丢失的状态；不用标签证明镜头外未发生某件事，也不复述正文已清楚的结果。
- 交稿前做一次经济性检查：是否添加题面没有的要求精确数字/记录链，是否用标签/对白重复动作。无新作用的内容删掉。
- 输入给目标时长时按真实表演/动作/停顿通读压稿，先删重复验证/解释与同义收尾；不用统一字数/镜头数/节拍数填模板。
- 用户原文优先；“去 AI 味”是局部修订，不抹平作者个性。

## 时长估算（按需）

用户问时长时才估算：按 `## EP001-SCxxx` 逐场切分，统计台词字数（按可朗读语速估算秒数）+ 动作段耗时可数事实，给出每场与整集估算，标“估算参考，不是门禁”。任务已给目标时长时，用真实朗读和身体通读判断能否容纳，直接压缩重复节拍。

## 完成

点名范围写入、场景因果连贯、对白与行动可表演、承诺可兑现或有意延迟、结尾完成本集预定的戏剧/情绪功能即完成。资产、分镜、审查、生产只在用户点名时开始。五份文档齐备后可转 `$short-drama` 做一次跨文档机械核对；内容质量仍由创作者审查
