# 短剧视频提示词

按分镜把单镜变化写成可复制、可执行的视频提示词，保存到 `剧集/<EP>/视频提示词.md`。源：Drama Skills 0.6.1（MIT）。

## 入口与边界
有当前分镜、冻结关键帧和必要视觉事实即可开始；图片提示词不是前置门槛。先按分镜的「输入参考图」选路径：
- 有可读真实 `REF-...` 图片时是**图生视频**；原样携带分镜中的槽位/顺序/相对路径/中文名/控制与不得控制、范围，静态身份/造型/地点/构图可由参考帧+视觉设定共同拥有。
- 「输入参考图：无」时是**文生视频**；必须写非空「静态视觉锚点」并把它原样纳入可复制正文，交代本镜必要的人群/造型/地点/构图/光线。不得只写 `preserve/keep/保持已有外观`。

## 工作流
1. 原样抄入分镜「参考图」，据此标「生成方式：图生/文生视频」。
2. 写不能动的静态框：图生以参考帧+视觉设定锁；文生把必要静态事实写入「静态视觉锚点」与可复制正文。
3. 确定本镜唯一主要变化与可验证终点。
4. 按“静态锚点 → 起点 → 触发 → 主体动作 → 次级反应 → 运镜 → 声音 → 终点”分秒段写。
5. 只在真实参考帧已说明静态外观时删重复描述，并保留防漂移约束。
6. 检查：不跨下一镜、不要求互斥动作、不让主体/道具瞬移变形。
7. 整集请求完成整集，镜头组只是内部批次。

## 提示词要求
- 从可见起点开始，以可验证终点结束；主体/动作对象/方向/幅度/速度/先后明确。
- 表演写动作与反应，不写无法执行的抽象结果；运镜不与人争注意力，复杂运镜要有叙事理由。
- 声音只写该镜需要的对白/画外音/环境/转场，不擅自补词。
- 正文可直接复制，含正文结构与禁止项，不含占位符/流程/路径/QA 结论。
- 时间线音乐：用户明确要求时增写独立章节，记使用区间、剧情功能、进出曲线、动态曲线与禁用；歌词必须来自用户提供或明确接受文本。静态漫剧只需关键帧切换+配音可跳过逐镜运动提示词。

## 完成与投产
每个点名镜头都有明确起点、主变化、时序、运镜/声音边界与可验证终点且与相邻镜头相连即完成。实际生成转 `$short-drama-produce`，先展示精确 job 并取得显式确认。五份文档齐备后可转 `$short-drama` 一次机械核对。
