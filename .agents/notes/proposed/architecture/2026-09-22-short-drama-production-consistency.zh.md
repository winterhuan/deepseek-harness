# Agent Note: 短剧生产一致性与成果归属

Status: proposed

[English](2026-09-22-short-drama-production-consistency.md) | 中文

## 问题

Creative 短剧工作台横跨创作文档解析、工作区读取、生产准备、后台作业和成果发现。目前这些层没有共同的一致性位置。工作台可以在协议诊断存在错误时提交准备请求；五份创作文档通过彼此独立的请求读取；成果归属通过输出路径中的 ID 片段恢复；TypeScript 投影解析器与 Python 创作者检查器对文档规则有重叠但不完全一致的实现。

这带来的不只是代码重复，而是可避免的不确定性：格式错误的文档可能进入准备流程；编辑过程中可能产生从未同时存在过的混合投影；重命名成果后可能归到错误目标；工作台接受的文档仍可能被创作者检查器拒绝。没有显式 ID 的视觉条目还会根据标题生成 ID，因此修改标题可能使选择、画布位置、引用和媒体归属失效。

## 提案

### 协议错误阻断生产

把错误级 `DramaProductionDiagnostic` 作为单项生产、批量准备和最终合成的前置条件。工作台继续显示警告，但禁用要求创作文档协议有效的操作。增加 Client 测试，证明每项被阻断的操作都不会提交；只有警告时仍允许操作。

### 一致读取一集文档

增加按剧集读取的操作，一次返回五份创作文档、各自的文件版本和读取批次 revision。工作台通过该结果调用 `parseEpisodeProduction()`，不再从 [workbench.tsx](../../../../packages/creative/creative/src/client/workbench.tsx) 分别发起文件读取。该操作必须保留脏缓冲区，并在读取期间文档发生变化时显示冲突；不能静默组合不同版本的读取结果。

### 显式记录成果归属

每个发布的媒体成果写入当前生产 manifest。每条记录包含目标 ID、生产请求 ID、可用时的框架作业身份、媒体类型、工作区路径和内容摘要。工作台把 manifest 作为权威归属来源。路径 ID 匹配只用于诊断未登记文件，不能单独给已登记成果分配目标。

### 让文档协议拥有一个可执行的权威

为 ID、字段、引用、视觉覆盖和错误标题定义共享的短剧文档 fixture 集合。TypeScript 投影测试和 `creator_markdown_check.py` 都运行这套 fixture。可以把共享结构解析器移到生成的或语言无关的表示中，也可以让 Client 投影消费 Python 检查器的结构化诊断，同时在 TypeScript 中只保留展示投影。最终行为必须明确哪些检查是结构阻断条件，哪些仍由人工审查负责。

### 要求稳定的视觉 ID

要求参与生产的视觉条目显式声明 `VISUAL-*` ID。缺失或无效 ID 仍然显示诊断，但不能创建生产目标。不要从可变标题推导持久目标身份；仅用于展示的标题 slug 可以继续存在。

## 已考虑的替代方案

**保留当前宽松 UI，依靠 `short-drama-produce` 拒绝无效任务。** 拒绝：创作者只能在模型可见的准备失败之后才得到反馈，而工作台已经拥有诊断信息，可以在请求进入 Session 前阻止它。

**继续分别读取文件，再选取最新结果对账。** 拒绝：独立版本可能组成磁盘上从未同时存在过的文档集合，选择最新结果也不能证明跨文档一致。

**保留路径匹配，只改进正则表达式。** 拒绝：正则无法在重命名后保留归属，也无法区分路径都包含同一目标片段的两个合法成果。生产操作已经知道目标和请求身份，应该保存这些事实。

**把 Python 检查器复制到 TypeScript，或把 TypeScript 解析器复制到 Python。** 拒绝：继续复制只会保留造成漂移的问题。在扩展任一实现前，必须先共享 fixture 并明确所有权。

**使用标题加内容摘要生成视觉 ID。** 拒绝：内容派生 ID 仍会随创作者有意编辑而变化，也掩盖了缺少创作者身份声明的问题。显式稳定 ID 更清楚，并且已经是协议词汇。

## 验收标准

- 协议错误会在 `beginSubmission()` 之前阻断生产、批量生产和合成；警告仍然可处理但不阻断。
- 一集投影来自同一个读取 revision；并发编辑会显示冲突或触发重试，而不是产生混合文档。
- 发布的媒体成果携带显式 manifest 归属和摘要；工作台中的已登记成果不依赖文件名启发式。
- 共享 fixture 覆盖 TypeScript 与 Python 检查共同消费的有效和无效结构，包括重复 ID、未知引用、错误标题、缺少视觉 ID 和引用语法。
- 没有有效 `VISUAL-*` ID 的视觉条目不能成为生产目标；修改标题不会静默改变已有目标 ID。
- Client、生产工具、短剧 selftest、快照和文档检查覆盖修改后的行为。

## 风险

manifest 会增加项目产物，并要求成果发布与其元数据保持原子性；发布不完整时必须显示成果不可用，而不能留下部分归属。按剧集读取可能增加响应体积，需要继续限制单份文档大小。要求视觉 ID 会让创作文档更严格，需要补充作者指南。共享 fixture 本身不会让两个解析器自动等价；各检查仍必须声明每条规则由哪一层执行。
